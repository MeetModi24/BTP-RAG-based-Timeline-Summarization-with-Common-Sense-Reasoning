544. LETTER TO MANGALA S. PATEL
YERAVDA MANDIR,
July 31, 1932
CHI. MANGALA,
You certainly do not wish that I should write the first letter
only to you every day? If I did that, it would only be called
partiality. Hence I should make it a rule to write first only to
the person whose letter is received first. Is that not fair?
BAPU
From the Gujarati original: C. W. 11099. Courtesy: Pushpa Naik
